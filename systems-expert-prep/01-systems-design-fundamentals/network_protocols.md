# Network Protocols & Fundamentals

## Prerequisites

### Client & Server
Client requests data, server provides data.

### IP Address
IPv4 format: a.b.c.d (0-255)

## Key Terms

### IP
Internet Protocol - foundation for machine-to-machine communication.

### TCP
Protocol built on IP for ordered, reliable data delivery.

### HTTP
HyperText Transfer Protocol - common protocol on top of TCP.

### IP Packet
Smallest unit of data sent over IP with header and payload.
